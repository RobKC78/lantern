# Windows installation

Download `Lantern-Setup-0.1.0.exe` from the repository downloads folder. Double-click it, follow the installation wizard, then open **Lantern Diagnostics** from your desktop or Start menu. Python is bundled. Installation is per-user; normal diagnostics do not require administrator access. Supported repairs request separate approval and elevation.

The dashboard opens in your browser. Keep the accompanying app terminal open until you choose Stop in the dashboard. Uninstall through Windows Settings > Apps.

This unsigned test build may trigger a Windows reputation warning. The packaged executable was tested on the development Windows computer: it started, served the dashboard and completed diagnostic collection. Clean-machine installation, upgrades and uninstall have not yet been tested. AI research requires the separately configured hosted service.
